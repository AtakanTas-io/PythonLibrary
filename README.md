# Python Utility Experiments

A small collection of Python scripts created while practicing automation and common utility tasks.

This repository is a **learning/scratch collection**, not a packaged Python library. The scripts are independent experiments and currently do not expose a stable public API or installable package.

## Current contents

The repository currently includes experiments for:

- background removal (`BackgroundRemovver.py`)
- QR-code generation (`QRGenerator.py`)
- PDF/document conversion experiments (`PDFconverter`, `main.py`)
- sample image, PDF, DOCX and generated QR artifacts used while testing the scripts

## Why this repository exists

I use this repository to practice working with Python packages, files and small automation tasks. More complete engineering projects are maintained separately; this repository intentionally remains a collection of small experiments.

## Status

Learning repository. It is not intended to be presented as a production-ready reusable Python package.
